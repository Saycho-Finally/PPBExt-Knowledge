## 一、已识别文献的核实与细化（K1 / K2）

### 1.1 Engram Adapter（arXiv 2608.29327，EMNLP 2026 Findings）

已核实。作者 Jiayu Hou、Lei Wang（电子科技大学）。**修正我们此前笔记的一处偏差**：

- 评测模型是 **Qwen3-4B 与 Qwen3-8B 两个**（此前笔记只记了 4B）
- 适配任务：AG-News 与 MedMCQA；OOD 覆盖推理/翻译/代码/法律推理
- OOD 保持 99.4%-100.1%（与笔记一致）
- 机制结论：OOD 激活非零，但门与投影衰减把残差压到**隐藏态范数的约 0.08%**，
  KL 漂移小、精度变化可忽略（与笔记一致）
- 论文的核心框架是"**何时适配**"（when to adapt）：n-gram 多通道匹配 + 占用跟踪做
  选择性先验，标量门抑制不连贯的 OOD 检索

**与本项目的对照**（维持既有结论，细化一处）：
同构点为"冻结基座 + 条件激活 + n-gram 先验"；差异仍是**结构性**的——他们的门衰减后
残差非零（0.08% 范数量级），我们的路由是结构性零执行（未路由输入逐位为零，且在
第二个模型上复测成立）。此外他们没有真伪门（内容门），也未测"知识注入 vs 程序注入"
的边界。

### 1.2 DeepSeek Engram（Conditional Memory via Scalable Lookup）

已核实。DeepSeek 与北京大学合作，2026-01-12 发布并开源
（github.com/deepseek-ai/Engram），梁文锋为作者之一。可回填的细节：

- 定位：条件记忆作为 MoE 之外的**新稀疏维度**；现代化 N-gram 哈希查找，O(1)
- **U 型缩放定律**：固定总参数与激活参数下，把 20%-25% 的稀疏预算分给记忆
  （ρ ≈ 0.75-0.80）最优；10B 规模验证损失从 1.7248 降至 1.7109
- Engram-27B（5.7B 记忆参数）对同规模纯 MoE：MMLU +3.4 / CMMLU +4.0 / BBH +5.0 /
  HumanEval +3.0 / MATH +2.4 / GSM8K +2.2
- 长上下文：Multi-Query NIAH 84.2 → 97.0，Variable Tracking 77.0 → 89.0
- 工程：嵌入表放主机内存、PCIe 异步预取，吞吐损失 <3%；插在第 2 与第 15 层；
  tokenizer 压缩使 128k 词表有效规模减少 23%；记忆维度 1280、8 个哈希头
- 团队结论：条件记忆将成为下一代稀疏模型不可或缺的建模基元

**与本项目的对照**：Engram 是**预训练架构**（把记忆做进模型），Engram Adapter 是
**后置适配**（复用预训练条件记忆），本项目是**冻结基座上的后置注入 + 注入决策的
测量学**。三者处在不同层；本项目与之不构成竞争，但其 U 型配比结论说明
"记忆/计算的分配比例"本身是一个被认真研究的量。

## 二、查新发现的高度相关近期工作（必须补进相关工作）

这一节是本轮检索的主要产出：**同方向、时间很近、此前未收录**的工作。

### 2.1 DMoE：Decoupled Mixture-of-Experts for Parametric Knowledge Injection
（arXiv 2606.14243，清华大学）

**与本仓库重叠度最高的工作，必须正视。** 要点：

- 把专家与路由器**都**从基座解耦；外部知识语料转成可独立更新的专家模块
- **不确定性感知路由器**：仅在基座知识不足时激活相关专家
- 专家只挂在**最后一层 FFN**，明确以**保留 KV-cache 复用**为设计目标

对照：模块化注入 + 按需激活 + 缓存兼容，三点都与我们重合。差异：(1) 他们训练专家模块
（参数化知识），我们在冻结基座上注入并测量注入决策本身；(2) 他们的路由是学习出的
不确定性判据，我们的是确定性词法路由 + 结构性零执行；(3) 我们给出样本量的**相变曲线**
（16→256：0 → 0.375 → 0.938 → 1.000）与知识/程序边界（程序注入 seen 1.000、
unseen 精确 0.000），这类**测量学结果**他们没有。

### 2.2 The Router Within（Gavel，arXiv 2609.15982，2026-09-14 提交，v2 09-28）

**对 PPBDec-Core 光谱的直接佐证。** 要点：

- 主张：**冻结的 agent LLM 自身的前向传播里就携带路由信号**，两个线性映射即可读出，
  上下文无需放入任何技能文本
- 两步：glance（用任务的中层隐状态对照每个技能安装时建好的紧凑向量库打分）+
  verdict（续跑入围技能的前向传播，读模型自身的似然与 yes/no 判断，与 glance 按
  专家乘积融合）；仅训练这两个映射
- Qwen3-32B 上胜过 progressive disclosure 与 retrieve-and-rerank 流水线
  （后者额外引入 1.2B-16B 参数），最高 +21.9 点

对照：这正是 PPBDec-Core 判定器光谱里 **`small_probe`（内部表示探针）档**的设计假设——
该档此前因"无调用方"被标记为未实现。Gavel 证明了这一档在真实系统中成立且有竞争力，
后续若接入，按 SPEC 类型学补位即可。

### 2.3 TokenMem：Faithful Knowledge Injection for Frozen LLMs

要点：知识冲突下 RAG 失效被归因为**架构性**——检索段落与模型自身 token 竞争同一个
attention softmax，参数记忆通常赢；解法是为检索知识开**独立 softmax 的 cross-attention
通道**，保证知识 token 上的注意力质量恒为 1；3-7M 参数门控适配器、两阶段课程。
冲突场景知识遵从率 69-70%（Qwen3-4B）对原生 RAG 的 20-52%。
（第三方评审指出其缺少训练基线对照、理论保证表述过强——引用时保留这两点。）

对照：解决的是"注入的知识**听不听话**"（knowledge conflict），与我们的
"注入**决策**怎么做、注入多少才够"正交。

### 2.4 Knowing-Using Gap（arXiv 2607.08393）

**本项目"程序注入失败"发现的形式化对应物，必须引用。** 要点：

- 形式化"记住但不会用"：精度差距 + 记忆化与泛化之间的**时间滞后**
- 机制：知识回路错位——记忆表征存在内部，但**未被路由到计算有效的层**
- 自我修补（self-patching）扫描全部层对；提出层间表征自蒸馏（LRSD），
  在 Qwen 上把多跳链式推理精度近乎翻倍而记忆不受损
- 实验图显示：记忆化在 epoch 15 达到 >0.95 而泛化始终接近 0

对照：我们实测的"程序注入（seen 1.000 / unseen 0.000）"与"中层插入修复记忆不修复
泛化"正是该现象在 4B 消费级硬件上的一个数据点。我们的增量不在发现本身，而在
**样本量坐标**（16→256 相变）与**逐位测量方法**。

### 2.5 其他（简要收录）

- **Rote Learning Considered Useful（ICLR 2026）**：两阶段"先机械记忆、后语义泛化"——
  用语义无关键 token 记忆事实关联，再用少量有语义提示微调唤起泛化。与我们
  "合成代号域"的设计同思路，可作为该设计的文献支点。
- **知识灌注缩放定律 / Memory Collapse（EMNLP 2025 Main）**：过量灌注导致记忆崩塌，
  每个模型存在临界灌注量且随规模可预测（F*(C) = A/C^α + E）。与我们的相变方向相反
  （他们研究"注太多"，我们研究"注多少才够"），互补。
- **HyperNetwork 知识注入（arXiv 2607.19604，Nace AI + Purdue）**：第三条路——超网络
  从事实批量生成 LoRA 适配器，基座恒冻结；给出系统性缩放定律与 MegaWikiQA（10M+ QA）。
- **Prometheus Mind**：冻结模型外挂记忆三件套（Memory Encoder / Retrieval Router /
  cross-attention 注入接口），检索 QA 绝对提升 +23%，开销 <15ms/查询。
- **GAG（2026-01-13）**：把私有知识做成紧凑专家模态，在冻结基座嵌入空间的固定锚位
  注入专家向量，可选择性、域限定、可逆。

## 三、bf16 方法论的外部实证（本仓库方法论部分的外部支点）

本轮检索找到三篇直接支撑我们"执行噪声必须逐位测量"立场的 2026 年工作：

1. **Greedy Decoding Is Not Precision-Invariant（arXiv 2609.26621，TMLR 已接收）**：
   同一 checkpoint、同一提示、贪心解码，BF16 与 FP16 产出不同 token 序列——
   六个模型（1.1B-7B，Llama/Qwen/Mistral/OLMoE）上 **49%-100% 的贪心生成发散**；
   **Qwen2.5-3B 的 GSM8K 上 19% 的提示最终答案翻转，而聚合精度只移动约 1 个点**，
   作者称之为"漂移藏在基准分数里"。机制是"边际事件"而非误差幅度事件。
2. **跨 GPU 非确定性（arXiv 2609.25624）**：同一模型在 A100/L40S/H100 上因 GEMM
   内核与归约顺序不同而发散。
3. **Flash Attention 的低精度系统性偏差（arXiv 2510.04212）**：BF16 累加存在**系统性
   负偏**（非随机噪声），因结构相似性而相干累积、不抵消，最终导致损失爆炸；
   提出 Stabilized Flash Attention。

对照：我们"bf16 执行噪声造成约 80% 全局激活漂移"的三分解，与 1 的结论在同一方向；
1 的"聚合分数掩盖逐样本翻转"是我们坚持逐位测量的直接外部理由；且 1 指出
**"路由决策在 logit 差距很小时最暴露"**——我们"未路由输入逐位为零"的结构性设计
恰好消除了这一暴露面。

## 四、对路线的影响

1. **"模块化知识注入进冻结基座"已是拥挤赛道**（DMoE / TokenMem / GAG / Prometheus
   Mind / HyperNetwork / Engram Adapter）。本仓库的定位表述应继续收紧为：
   **注入决策的测量学**（相变曲线、知识/程序边界、逐位纪律、消费级硬件坐标），
   而不是"提出了一种注入方法"。
2. **Gavel 的出现把 `small_probe` 档从"理论位"变成"已证实可行"**，PPBDec-Core 的
   光谱缺口表应加注此文献。
3. **Knowing-Using Gap 应成为"程序注入失败"的标准引用**；我们的数据点价值在于
   4B 消费级硬件 + 样本量坐标。
4. bf16 三篇（2609.26621 / 2609.25624 / 2510.04212）应进入本仓库 bf16 方法论文档的
   引用列表——它们把"精度不变性不能假设"从我们的经验观察升级为 2026 年的公认结论。
